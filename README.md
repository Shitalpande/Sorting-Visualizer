## Sorting-Visualizer

### Sorting Algorithm Visualizer (Python, Tkinter)
I developed an interactive Sorting Visualizer using Python and Tkinter to demonstrate how popular sorting algorithms work in real time. The tool visually represents data as bars, allowing users to observe each comparison, swap, and partition step-by-step. It supports algorithms like Bubble Sort and Quick Sort, with dynamic animations that highlight the currently processed elements using color transitions for better understanding.

The application includes user-friendly controls to generate random datasets, adjust data size, define value ranges, and modify sorting speed. I implemented modular functions for sorting, partitioning, drawing bars, and UI handling to ensure clean structure and easy scalability.

This project improved my understanding of algorithm complexity, recursion, real-time rendering, and event-driven GUI design. It serves as an educational tool to help learners visualize how sorting algorithms behave internally.
